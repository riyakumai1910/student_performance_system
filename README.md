# Student Performance Analytics System

## About the Project
This project is developed using Python to analyze student marks and attendance and understand their academic performance.

## Objectives
- Analyze student marks.
- Calculate average marks.
- Find highest and lowest marks.
- Analyze student attendance.
- Generate student performance results.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV

## Project Files
- `main.py` – Main Python program
- `dashboard.py` – Dashboard
- `student.csv` – Student data
- `final_result.csv` – Student analysis results

## Features
- Student performance analysis
- Student search
- Marks and attendance analysis

## How to Run
1. Install Python.
2. Install the required libraries.
3. Run `main.py`.

## Future Scope
- Add more visualizations.
- Improve student performance reports.
